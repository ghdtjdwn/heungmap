# 기획자 흐름 검토용 프로토타입

기획자 Tier 0의 4단계 입력, 검토와 mock 결과 구조를 빠르게 확인하기 위한 정적 프로토타입입니다. 실제
API, 수요 예측, 저장, 로그인과 LLM을 사용하지 않으며 제품 frontend 구현으로 간주하지 않습니다.

저장소 루트에서 실행합니다.

```bash
python3 -m http.server 4173
```

브라우저에서 <http://localhost:4173/prototype/planner/>를 엽니다. `예시 채우기`로 소규모 독립 기획자
scenario를 채운 뒤 다음 단계와 mock 결과까지 확인할 수 있습니다.

확인할 항목은 질문 순서, 필수·선택 입력, 날짜·지역 조건부 노출, 모바일 배치와 예측 불가 상태의 이해
가능성입니다. 시각 디자인과 component 구현은 공통 Next.js scaffold 이후 다시 만듭니다.
