# 공모전 심사기준과 개발 대응

## 목적

기능과 개발 순서를 심사기준에 연결해, 기능 수보다 과제 적합성·완결성·데이터 근거·사용 가치를 우선한다. 작업을 시작할 때 기여할 평가항목과 완료 조건을 적고, 기능 검토와 제출 전 자체 점검에 이 문서를 사용한다.

## 1차 심사 — 기능심사 100점

| 항목 | 배점 | 흥할지도 대응 |
| --- | ---: | --- |
| 서비스 구현성(과제 연계기능 완결성·구동 안정성·완성도) | 30 | 과제 9번 핵심 흐름을 end-to-end로 구현하고 외부 API 오류·빈 응답에도 기본 기능 유지 |
| 서비스 기획력(타당성·구체성·독창성) | 30 | 주관적 축제 기획 문제를 데이터로 검증하고 하나의 예측 결과를 기획자와 방문객에게 연결 |
| 데이터 활용 적절성(한국관광공사 OpenAPI 필수) | 20 | TourAPI를 축제 탐색과 주변 관광정보의 기준 데이터로 사용하고 출처·가공·예측 과정을 제시 |
| 서비스 발전성(지속성·확장성) | 20 | 같은 구조로 지역·축제·데이터 소스를 확장하고 운영 가능한 재현 절차와 fallback 확보 |

### 1차 개발 원칙

- 새 기능 수보다 과제 9번과 직접 연결된 핵심 흐름의 완결성과 안정성을 먼저 확보한다.
- TourAPI는 장식용 로고나 단순 링크가 아니라 실제 사용자 흐름과 데이터 처리에 사용한다.
- 발전성은 미완성 기능을 늘리는 방식이 아니라 현재 구조가 다른 지역·축제·데이터로 확장되는 과정을 보여준다.
- 기능마다 심사항목, 사용자 가치, 담당자, 입력·출력, 완료 조건, 검증 방법을 기록한다.

## 최종 심사 — 발표심사 100점

| 항목 | 배점 | 흥할지도 대응 |
| --- | ---: | --- |
| 서비스 적정성(명확성·논리성·시의적절성) | 30 | 문제, 데이터, 해결 방식과 기대효과를 하나의 일관된 이야기로 설명 |
| 서비스 완성도(기능 구현도·데이터 활용성·안정성) | 30 | 핵심 흐름을 실제 구동하고 데이터 출처·처리·예측·예외 대응을 증명 |
| 서비스 실용성(활용성·이용 편의성·지속성) | 25 | 기획자와 방문객의 구체적인 사용 시나리오, 쉬운 화면과 운영·확장 방안 제시 |
| 발표점수 | 15 | 문제→해결→데이터→시연→검증 결과→발전 계획 순으로 발표하고 시연 장애에 대비 |

### 최종심사 준비 원칙

- 발표의 주장과 실제 구현 범위를 일치시키고 데이터와 모델의 한계를 숨기지 않는다.
- 기획자와 방문객이 언제, 왜 사용하는지 구체적인 데모 시나리오로 보여준다.
- 핵심 기능의 정상 경로와 외부 API 오류·데이터 없음 상황을 모두 점검한다.
- TourAPI 활용 지점과 자체 가공·예측 과정을 화면과 발표 자료에서 추적할 수 있게 한다.
- 라이브 시연 실패에 대비해 동일 흐름의 짧은 녹화 영상과 핵심 화면 캡처를 준비한다.

## 기능 우선순위 판단 순서

1. 과제 9번 핵심 흐름의 완결성과 구동 안정성
2. 한국관광공사 OpenAPI의 핵심 활용과 데이터 근거
3. 데이터 기반 예측의 타당성·구체성·독창성
4. 기획자·방문객의 실제 사용 편의와 활용성
5. 지역·축제·데이터·사용자 확장 가능성
6. 발표에서 짧고 명확하게 증명할 수 있는가

기여가 불분명하거나 기반 제품 완성을 늦추는 기능은 뒤로 미룬다. 로그인·추천·LLM 같은 기능을 불완전하게 추가하기보다 하나의 예측 엔진과 두 사용자 흐름을 안정적으로 완성한다.

## 자체 점검표

- [ ] 문제와 대상 사용자를 한 문장으로 설명할 수 있다.
- [ ] 기획자 입력부터 결과까지 핵심 흐름이 실제로 동작한다.
- [ ] 방문객이 실제 축제를 찾고 수요 지표와 주변 정보를 확인할 수 있다.
- [ ] TourAPI가 사용된 화면·필드·호출과 출처를 제시할 수 있다.
- [ ] 실제값·추정값·예측값·상대지수를 정확히 구분한다.
- [ ] 데이터 수집·가공·결합·예측을 재현할 수 있다.
- [ ] 외부 API 오류와 데이터 없음 상태가 처리된다.
- [ ] 모바일·데스크톱에서 핵심 흐름을 어렵지 않게 사용할 수 있다.
- [ ] 확장 계획이 현재 구조와 연결되고 과장되지 않았다.
- [ ] 제한 시간 안에 시연과 핵심 메시지를 전달할 수 있다.
