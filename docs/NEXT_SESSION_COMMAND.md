## 남은 조건과 금지 사항

- 학습 모델은 시간 분할에서 baseline보다 나빠 제품 채택 보류, SHAP도 미연결이다.
- 실제 Google 프로젝트 설정·실계정 왕복과 운영 배포는 미완료다. 기기 간 초안 동기화도 제공하지 않는다.
- 문서의 폭넓은 입력·feature, 예매·결제·즐겨찾기·알림은 추후 후보이지 이번 완료 기능이 아니다.
- 지역 방문자·mock 상대지수를 실제 축제 관람객 수나 검증된 예측 성능으로 표현하지 않는다.
- 비밀값·원본 및 가공 데이터·SQLite·모델·캐시·빌드 산출물은 Git과 기록에서 제외한다.
- 추가 commit·push·PR 변경·merge·배포는 사용자가 해당 전달 단계를 요청한 경우에만 수행한다.
- 작업 기록은 세션 종료 문서 정리 요청이 있을 때만 관련 작업을 합쳐 프로젝트당 한 항목 작성한다.
